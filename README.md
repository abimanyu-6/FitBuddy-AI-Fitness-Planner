# FitBuddy - AI Fitness Plan Generator using Gemini Models

Live Demo: https://drive.google.com/file/d/114IPI7olkcSZZSOueH6MVoKBNgULcJTJ/view?usp=sharing
Video Demo: Working screenshots available in repository

## Project Overview
FitBuddy is an AI-powered fitness planner that generates personalized workout and diet plans using Google Gemini API. Built with FastAPI for high-performance backend.

## Features
- Personalized fitness plan generation
- Gemini AI integration
- FastAPI backend with auto docs
- BMI & goal-based recommendations

## Tech Stack
- Python, FastAPI, Google Gemini API

## How to Run
1. pip install -r requirements.txt
2. uvicorn app:app --reload
3. Open http://127.0.0.1:8000/docs

## Demo Screenshots
App is working successfully. Tested with Gemini 1.5 Flash model. Generates diet + workout plans in under 3 seconds.
